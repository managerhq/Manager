United Kingdom

This extension helps United Kingdom businesses with the country's compliance reports and the tax codes those reports depend on.

Business

Installing a report adds it to this business's Reports tab in Manager, where it can be run any time.

The country ships with a standard set of tax codes pre-linked to the reporting categories the reports use. Create any that are missing in this business with a single click, or update an existing code to attach the right reporting categories.

Per-row buttons create or update one tax code at a time.
